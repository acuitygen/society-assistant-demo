# Society Assistant: interactive demo

**Live demo:** https://acuitygen.github.io/society-assistant-demo/

This is a clickable front-end prototype of **Society Assistant** by AcuityGen. It pairs a WhatsApp assistant with a members' dashboard for residential housing societies in India.

> **Demo, sample data.** Every name, flat, phone number and message is invented. The page is static. It has no backend and makes no WhatsApp, email or AI calls.

## What you can try
- **WhatsApp assistant (simulated):** raise a complaint, check its status, request an NOC, ask a question.
- **Complaints board:** the 5-step workflow (open → work in progress → closed by member → verified by manager → approved by secretary).
- **Notices and broadcasts, documents, vendor directory, NOC requests, AMC renewal alerts, emergency contacts.**
- **Email history search** (scripted, secretary only).
- **"Preview as"** switcher: member, society manager or secretary.
